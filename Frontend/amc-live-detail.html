How AutoMediaStream Works

Everything you need to access your live stream content, in four steps.

1
Check the Countdown
The countdown shows exactly when the stream is scheduled to go live. You'll be able to join the early access window before the official start.
2
Stream Goes Live
At the scheduled time the stream will go live. Use the view toggle buttons in the toolbar to switch between regular, mid and full screen formats.
3
Watch and Take Notes
The Notes tab allows you to add timestamped observations as the stream plays. Notes can be downloaded after the stream ends.
4
Access the Replay
Once the stream ends it moves to Archive on the Media Live page. Use the All Events button to return to the main menu. You can replay it at any time.
