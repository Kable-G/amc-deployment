## 🔄 Page Migration Process

### **Step 1: Identify Current System**

**Current Enterprise Sidebar System:**
```html
<!-- Current system uses -->
<link rel="stylesheet" href="css/sidebar.css">
<script src="components/sidebar.js"></script>
<aside id="sidebar" class="amc-sidebar">
    <!-- Content generated by components/sidebar.js -->
</aside>
```

**New Global Shell System:**
```html
<!-- New system uses -->
<link rel="stylesheet" href="css/globalheader.css">
<link rel="stylesheet" href="css/globalshell.css">
<header id="amc-header" class="app-header"></header>
<aside id="amc-sidebar" class="amc-sidebar"></aside>
<script type="module" src="components/globalsidebardata.js"></script>
<script type="module" src="components/globalsidebar.js"></script>
<script type="module" src="components/globalshell.js"></script>
```

### **Step 2: Page Template Conversion**

#### **A. Update HTML Structure**

**BEFORE (Current System):**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
    
    <!-- Enterprise Sidebar System -->
    <link rel="stylesheet" href="css/sidebar.css">
    <script src="components/sidebar.js"></script>
    
    <!-- Other CSS/JS -->
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.2.0/css/all.min.css">
    <link rel="stylesheet" href="amc-avatar-styles.css">
</head>
<body>
    <!-- Current sidebar -->
    <aside id="sidebar" class="amc-sidebar">
        <!-- Auto-generated content -->
    </aside>
    
    <!-- Main content -->
    <main class="main-content">
        <!-- Page content -->
    </main>
</body>
</html>
```

**AFTER (Global Shell System):**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Page Title</title>
    
    <!-- Fonts & Icons -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css"/>
    
    <!-- Global Shell System -->
    <link rel="stylesheet" href="css/globalheader.css">
    <link rel="stylesheet" href="css/globalshell.css">
</head>
<body>
    <!-- Global header -->
    <header id="amc-header" class="app-header"></header>
    
    <!-- Global sidebar -->
    <aside id="amc-sidebar" class="amc-sidebar"></aside>
    
    <!-- Main content -->
    <main id="amc-slot" class="amc-main">
        <!-- Page content -->
    </main>
    
    <!-- Global Shell Scripts -->
    <script type="module" src="components/globalsidebardata.js"></script>
    <script type="module" src="components/globalsidebar.js"></script>
    <script type="module" src="components/globalshell.js"></script>
</body>
</html>
```

#### **B. Update CSS Classes**

**Class Mapping:**
```css
/* OLD → NEW */
.main-content → .amc-main
#sidebar → #amc-sidebar
.amc-sidebar → .amc-sidebar (same)
```

#### **C. Remove Old Dependencies**

**Remove these lines:**
```html
<!-- Remove old system -->
<link rel="stylesheet" href="css/sidebar.css">
<script src="components/sidebar.js"></script>
<link rel="stylesheet" href="amc-avatar-styles.css"> <!-- Now built into global system -->
```

### **Step 3: JavaScript Integration**

#### **A. Remove Old Initialization**
```javascript
// REMOVE old sidebar initialization
document.addEventListener('DOMContentLoaded', function() {
    // Remove any manual sidebar initialization
});
```

#### **B. Add Global Shell Integration**
```javascript
// OPTIONAL: Custom page initialization
document.addEventListener('DOMContentLoaded', function() {
    // Set current page for active state
    window.amcCurrentPage = 'current-page.html';
    
    // Custom cart/notification setup if needed
    amcSetCartCount(0);
    amcSetNotifCount(0);
});
```

## 🚨 Common Migration Issues & Solutions

### **Issue 1: CSS Conflicts**
**Problem:** Old CSS conflicts with new Global Shell CSS
**Solution:**
```css
/* Add specificity to page-specific styles */
.amc-main .your-page-class {
    /* Your styles */
}

/* Or use CSS custom properties */
.your-element {
    color: var(--sidebar-text);
    background: var(--sidebar-bg);
}
```

### **Issue 2: JavaScript Module Errors**
**Problem:** ES6 modules not loading
**Solution:**
```html
<!-- Ensure proper module loading -->
<script type="module" src="components/globalsidebardata.js"></script>
<!-- Add fallback for older browsers if needed -->
<script nomodule src="components/globalsidebardata-legacy.js"></script>
```

### **Issue 3: Layout Shifts**
**Problem:** Content jumps when shell loads
**Solution:**
```css
/* Add loading state styles */
body:not(.shell-loaded) .amc-main {
    opacity: 0;
    transition: opacity 0.3s ease;
}

body.shell-loaded .amc-main {
    opacity: 1;
}
```

### **Issue 4: Role Detection**
**Problem:** Wrong sidebar menu appears
**Solution:**
```javascript
// Ensure role is set before shell initialization
localStorage.setItem('amc_user_role', getCurrentUserRole());

// Or use the public API
AMCShell.updateRole(getCurrentUserRole());
```
