🔧 Clear Authentication Tokens

This will clear all stored authentication tokens and user data from your browser's localStorage.

Current Stored Data:

Manual Instructions:

  1. Open Developer Tools (F12)
  2. Go to Application/Storage tab
  3. Find "Local Storage" → "http://127.0.0.1:5500"
  4. Delete these keys: token, authToken, user, currentUser
  5. Refresh the page and try logging in again
